# Group20 第四阶段验收

第四阶段对应 11 月 21–24 日。验收复核于 2026 年 11 月 28 日完成，基线为已合并第三阶段的 `e01cb86`。

| 分工 | 实现与验收 |
| --- | --- |
| A 页面对照 | 对照仓库已有的选电影和全部短评截图。修正地区按钮与筛选工具的重叠、短评信息的层次和分隔、页脚对齐。复核选电影在 1440 和 390 像素宽度下的布局。 |
| B 后端 | 已登录用户可将地区、类型、评分区间、排序和未看过条件组合使用。服务端在分页前过滤，只排除当前用户标记为「看过」的条目。短评改删限定作者本人，观影状态和短评保存在 H2。 |
| C 前端 | 选电影、选剧集和 Top 250 接入筛选。刷新及登录返回可恢复电影筛选。无结果隐藏页码，连接失败允许重试，评分区间无效时提示修正。短评保存或删除失败时保留当前编辑内容。 |

| 复测场景 | 结果 |
| --- | --- |
| 首页 → 排行榜 → Top 250 翻页 → 搜索 → 详情 → 登录 | 通过 |
| 多条件同时生效、刷新恢复、加载更多、无效评分、空结果、超范围页码恢复 | 通过 |
| 登录后恢复「未看过」，标记看过即移出，对另一账号的列表无影响 | 通过 |
| 短评发表、评分、改删、另一账号改删返回 403、服务重启后数据保留 | 通过 |
| 详情和短评首次加载失败、可重试错误恢复、未知影片提示 | 通过 |
| 保存和删除请求失败后草稿仍在，同一浏览器切换账号后保留草稿，登录原账号后可继续保存 | 通过 |

Java 21 执行 `mvnw.cmd clean verify`，8 项集成测试通过。另使用 Edge 验证上述浏览器流程。浏览器验收使用独立 H2 数据库。
