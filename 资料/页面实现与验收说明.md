# Group20 页面实现与验收说明

更新：2026 年 11 月 9 日。本文件取代历史阶段文件中的旧页面清单。页面依据 `资料/原站截图` 中的十类截图实现，后端工作仍由 B 负责。

## 页面与入口

| 原站参照 | 本地文件 | 主要行为 |
|---|---|---|
| 豆瓣电影首页 | `frontend/index.html` | 点击左上“豆瓣电影”返回；热门电影切换、热映卡片、搜索入口。 |
| 影讯&购票 | `frontend/showing.html` | 独立票务列表页；正在上映、即将上映和城市显示。真实购票未接入。 |
| 选电影 | `frontend/explore.html` | 地区、评分、排序、未看过、可播放及加载更多。 |
| 选剧集 | `frontend/tv.html` | 剧集类型、评分、排序、未看过及加载更多。 |
| 排行榜 | `frontend/chart.html` | 新片榜与侧栏榜单；侧栏“豆瓣电影 TOP250 · 全部”进入下一页。 |
| Top 250 | `frontend/top250.html` | 每页 25 条、上一页／下一页、未看过过滤及标记。演示数据目前 35 条。 |
| 搜索结果 | `frontend/search.html?keyword=给阿嬷的情书` | 搜索电影名、原名、地区、类型和导演，支持空结果。 |
| 电影详情 | `frontend/movie.html?id=6` | 基本信息、原站评分快照、想看／看过互斥标记、短评入口。 |
| 全部短评 | `frontend/comments.html?movieId=6` | 热门／最新／好友、星级筛选、发表／修改／删除本人短评、投票。 |
| 演示登录 | `frontend/login.html` | 密码登录；短信标签只复刻界面，不发送真实短信。 |

顶部导航按提供的原站截图显示“我看、影讯&购票、选电影、选剧集、排行榜、影评、2025年度榜单、2025年度报告”，不放 Top 250 和电影详情按钮。点击“豆瓣电影”标志返回首页。导航里未单独复刻的栏目链接到本项目最接近的现有页面；这部分仍需最终演示时决定是否保留。

## 如何打开

在 `group20` 根目录打开终端，Mac 运行 `python3 -m http.server 8765 --directory frontend`，Windows PowerShell 运行 `py -m http.server 8765 --directory frontend`。Chrome 打开 `http://localhost:8765/`。直接双击 HTML 可能无法读取本地 JSON。

本地演示账号：`demo1`、`demo2`、`demo3`，密码都是 `demo123`。这些是写在前端中的公开测试账号，不能用于真实服务。登录、电影标记和短评保存在当前浏览器的 localStorage；刷新后仍在，换电脑或清理浏览器数据后不会同步。B 完成 Java 服务后必须改用同源 Cookie 会话与后端持久化，并用两个账号、重启服务重新验收。

## 当前可检查的流程

1. 首页左上标志 → 首页；顶部“影讯&购票” → 独立票务页；排行榜右栏“全部” → Top 250。
2. 首页搜索“给阿嬷的情书” → 搜索结果 → 电影详情 → 全部短评。
3. 登录 `demo1` → 在详情点击“想看”再点“看过” → 刷新页面检查标记；再次点击同一标记会取消。
4. 选电影切换“华语”和“8 分以上”，或在 Top 250 点下一页、勾选“只看我没看过的”。
5. 全部短评发表、修改、删除一条自己的短评；换 `demo2` 检查不能修改 `demo1` 的短评。

## 已知边界

- 页面区块、双栏结构、导航位置、列表密度和交互入口参照原站截图；海报目前是原创 CSS 占位图，广告为本地示意，尚未达到原站图片级一致。动态内容、电影资料与评分部分为演示数据，不可作为真实豆瓣数据引用。
- Top 250 只收录 35 条演示电影，因此能验证分页但不是完整 250 条。影讯页没有真实购票；短信登录没有短信服务。
- B 的 Java Spring Boot/H2 服务、Cookie 会话、服务端数据持久化及完整接口验收尚未完成。前端本地演示不代表课程项目全部完成。
- 公开仓库中的原站截图可能显示个人账号名称和消息数量；上传前应遮盖或从公开仓库排除。
