## 功能冻结

P0：首页到排行榜、排行榜到 Top 250 的跳转，导航、搜索（无结果提示）、榜单分页、基础筛选、电影详情、演示登录与退出、想看/看过互斥及重启后保留。P1：组合筛选与排序、我没看过的、星级和短评发表、修改、删除、本人权限验证。P2：短评有用投票，只有 P0/P1 稳定才做。不存在的条目返回 404，未登录修改返回 401，修改他人评论返回 403，参数错误返回 400；错误统一 JSON：{"error":"INVALID_ARGUMENT","message":"说明"}。

## 字段 冻结版本 v1

Movie：id 整数、title 字符串、originalTitle 字符串、year 整数、region 字符串、genres 字符串数组、director 字符串、originalRating 数字或 null（原站快照）、rank 整数或 null（Top 250 的名次）、newChartRank 整数或 null（排行榜新片榜快照名次，与 rank 分开）、posterUrl 字符串、synopsis 字符串。样例电影 id 为本地编号，与豆瓣编号不对应；字段统一使用这些拼写。映画数据样例见 电影样例数据.json，现有六条供双方对接口，非完成规模；placeholder 图片需后续准备。

User：id 整数、displayName 字符串；不要向前端返回密码。UserMovie：movieId 整数、status 为 WANT 或 WATCHED，删除状态用 null；同用户同电影唯一。Review：id、movieId、userId 为整数，author 为字符串，stars 为 1 至 5 整数，content 为字符串，createdAt、updatedAt 为 ISO 日期时间字符串。每用户对每部电影最多一条短评；原站评分与本地用户星级分开存储。

## 接口约定 JSON v1

所有请求和响应为 JSON，分页从 1 开始，默认 page=1、size=25；成功分页结构 {"items":[],"page":1,"size":25,"total":0}。以下接口是约定，当前均未实现。列表可接受 keyword、region、genre、minRating、maxRating、sort（rank、rating_desc、year_desc）和 unwatched（true/false，需登录）；指定条件同时生效，翻页保留条件。

- GET /api/movies：分页返回 Movie 列表。Top 250 使用 sort=rank，只包含 rank 非空影片；排行榜的新片榜使用 chart=new，仅返回 newChartRank 非空条目并按 newChartRank 升序。两个榜单分别存储名次，不用上映年份推断新片榜。
- GET /api/movies/{id}：返回单个 Movie；不存在返回 404。
- POST /api/session：请求 {"username":"demo1","password":"测试密码"}，返回 {"user":{"id":1,"displayName":"演示用户1"}}，会话以同源 Cookie 维持。账号仅供本地演示，由 B 创建并向队友提供，不使用真实账号。
- GET /api/session：返回 {"user":{...}} 或未登录返回 401；DELETE /api/session：退出，返回 204。
- GET /api/movies/{id}/status：已登录时返回 {"movieId":1,"status":"WANT"}，无标记时 status 为 null；PUT 同路径请求 {"status":"WANT"}、{"status":"WATCHED"} 或 {"status":null}，返回更新后的对象。
- GET /api/movies/{id}/reviews?page=1&size=10：分页返回 Review 列表。PUT /api/movies/{id}/review：请求 {"stars":5,"content":"测试短评"}，为当前用户创建或更新唯一短评，返回 Review。DELETE 同路径删除当前用户的短评，返回 204。

同一版本字段若需更改，先通知 A、B、C，再同步更新这份文件与前后端。原站截图或界面实际行为不同之处记录为待确认，不冒充已核查。
