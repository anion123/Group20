# Group20 豆瓣电影课程项目

本仓库现有十类前端页面：首页、影讯&购票、选电影、选剧集、排行榜、Top 250、搜索结果、电影详情、全部短评和演示登录。页面可本地预览并演示筛选、搜索、分页、登录、标记和短评。B 的 Java 后端尚未完成；当前浏览器交互使用明确标注的本地演示数据。

- frontend：前端页面及素材，A 与 C 负责。
- backend：Java 服务与数据，B 负责。
- 资料：冻结说明、六条电影样例及原站截图。

先阅读 [页面实现与验收说明](资料/页面实现与验收说明.md)。[第一阶段冻结说明](资料/第一阶段冻结说明.md) 与 [第二阶段 A 页面交接说明](资料/第二阶段A页面交接说明.md) 保留为历史记录，页面范围以最新说明为准。请确认仓库公开状态：原站截图中部分含账号名称与消息数量，上传前先处理个人信息，或将截图留在非公开的组内位置。演示账户仅使用自建测试数据。
